# Derby Women's Centre website

This folder is deployment-ready for GitHub Pages.

## Important
Do NOT upload these files into the root of the existing Spark & Spectrum GitHub Pages repository if that repository is already serving sparkandspectrum.org.uk.

Use one of these safer options:

1. Create a separate GitHub repository for Derby Women's Centre.
2. Connect the Derby Women's Centre domain to that separate repository.
3. Keep Spark & Spectrum in its existing repository/domain.

## Homepage
GitHub Pages expects the homepage to be named:

index.html

That file is included here.

## Site pages
- index.html
- find-support.html

- about-us.html
- whats-on.html
- funders-partners.html
- get-involved.html
- contact.html

## Before launch
Confirm the final Derby Women's Centre custom domain, then add that domain in the GitHub Pages settings for this repository.

If GitHub requests a CNAME file for the custom domain, create it in the repository root containing only the domain name, for example:

www.example.org.uk

Do not add a CNAME until the actual Derby Women's Centre domain is confirmed.
